引言

在 Notion、飞书文档、语雀等所见即所得编辑器大行其道的今天，可能有人会问：都 2025 年了，为什么还要学 Markdown 这种"原始"的标记语言？

答案可能出乎很多人意料：正因为时代在变，Markdown 才显得更重要。

一、为什么这个时代我们更需要学 Markdown？

1.1 数据主权：你的笔记真正属于你

使用 Notion、语雀等在线编辑器，你的数据存储在别人的服务器上。一旦服务关闭、账号被封、或者你忘记续费，所有的笔记都可能瞬间消失。

Markdown 文件是纯文本文件，它们：

  • 可以用任何文本编辑器打开
  • 不依赖任何特定软件或服务
  • 可以轻松备份、迁移、版本控制
  • 即使 50 年后依然可以被读取

1.2 通用性：写一次，处处可用

从 GitHub 的 README 到博客文章，从技术文档到学术论文，从即时通讯软件到邮件，Markdown 几乎无处不在。掌握它，你可以在任何需要格式化的地方快速表达想法。

1.3 效率：手不离键盘的写作体验

对于经常写代码的开发者来说，Markdown 让写作和编码一样流畅——不需要鼠标点击工具栏，双手始终在键盘上，思维和文字同步。

1.4 未来兼容性：与 AI 工具完美契合

在 AI 辅助写作的时代，Markdown 因其结构化特性，成为 AI 工具最容易理解和处理的格式。你可以轻松地将 Markdown 笔记喂给 AI，让它帮你整理、总结、扩展。

二、Markdown 语法指南

2.1 基础语法

1
2
3
4

## 二级标题
### 三级标题
#### 四级标题

无序列表：

2.3 实用技巧

  1. 善用空行：段落之间空一行，让渲染更清晰
  2. 代码块标注语言：在代码块开头标明语言，获得语法高亮
  3. 合理使用标题层级：不要跳过层级（如从 # 直接到 ###）
  4. 图片添加 alt 描述：提升可访问性

三、种草 Obsidian：你的第二大脑

3.1 什么是 Obsidian？

Obsidian 是一款本地优先的知识管理工具。它以 Markdown 文件为基础存储笔记，同时提供了强大的链接、图谱和插件系统。

简单来说：Obsidian = 本地 Markdown 文件 + 双向链接 + 知识图谱 + 无限插件扩展

3.2 为什么选择 Obsidian？

3.2.1 数据完全属于你

Obsidian 的笔记就是你电脑上的 .md 文件，不依赖任何云服务。即使 Obsidian 公司明天倒闭，你的笔记依然完好无损。

3.2.2 双向链接：让知识产生连接

传统笔记是孤立的，而 Obsidian 的双向链接让笔记之间可以互相引用：

1
2
3

[[另一篇笔记]]

这是关于 [[知识管理]] 的思考，与 [[笔记方法]] 密切相关。

点击链接即可跳转到相关笔记，形成知识网络。

3.2.3 知识图谱：看见你的思维

Obsidian 会自动生成图谱视图，将你的笔记以节点和连线的形式可视化。看着自己的知识网络逐渐壮大，是一种难以言喻的成就感。

3.2.4 插件生态：无限可能

Obsidian 拥有丰富的社区插件：

  • Dataview：像数据库一样查询笔记
  • Templater：强大的模板系统
  • Excalidraw：手绘风格绘图
  • Calendar：日历视图
  • Kanban：看板管理
  • AI 助手插件：接入大语言模型

3.3 Obsidian 核心功能入门

3.3.1 创建笔记

在 Obsidian 中新建笔记就是创建一个 .md 文件，可以使用 Markdown 语法编写。

3.3.2 链接笔记

使用 [[笔记名]] 语法创建内部链接，如果笔记不存在，点击会自动创建。

3.3.3 标签系统

使用 #标签 对笔记进行分类：

1

#读书笔记 #技术分享 #效率工具

3.3.4 每日笔记

开启"日记"插件后，每天可以一键创建当天的笔记，非常适合记录工作日志和灵感。

3.4 适合谁用？

  • 开发者：技术文档、代码笔记、问题排查记录
  • 研究者/学生：文献笔记、课程笔记、论文草稿
  • 写作者：博客草稿、创意写作、大纲整理
  • 知识工作者：会议纪要、项目管理、个人知识库

四、Markdown + Obsidian + Hugo 的工作流

作为一个技术博客作者，我的写作工作流是：

  1. Obsidian 中编写和整理笔记
  2. 将完成的笔记导出到 Hugo 博客仓库
  3. Git 推送到 GitHub，自动部署到 GitHub Pages

这种工作流的好处：

  • 写作和管理在一个地方完成
  • 博客发布自动化
  • 所有数据本地存储，完全可控

如果你对我的博客搭建过程感兴趣，可以参考我的上一篇文章：从零搭建个人技术博客

结语

Markdown 不是一个"过时的技术"，而是一种面向未来的写作方式。它简单、通用、持久，配合 Obsidian 这样的工具，可以构建出真正属于自己的知识管理系统。

在这个信息爆炸的时代，掌握 Markdown，就是掌握了一种将知识沉淀为资产的能力。
