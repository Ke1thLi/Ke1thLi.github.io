命令讲解

-sn —>(no port scan) 无端口扫描 作用是仅对主机进行存活嗅探，不进行端口扫描

sudo 的作用

  1. 发送原始数据包，组合使用多种探测技术进行扫描
  2. 会使用ICMP Echo请求、TCP SYN/ACK探测
  3. 高效，能绕过某些防火墙规则，但网络足迹更明显

不加sudo的特点（不仅是权限的不同）

  1. 使用系统connect()系统调用
  2. TCP connect（）扫描
  3. 会建立完整的TCP三次握手，网络足迹更常规，类似普通网络连接

SQL 注入分析

原始 SQL（推测）

SELECT * FROM users WHERE uid=’$uid’;

正常输入：

uid=1

SELECT * FROM users WHERE uid=‘1’;

结果：

admin

输入：

uid='

SQL 结构被破坏

MySQL 返回语法错误

输入：

uid=1’ – -

SELECT * FROM users WHERE uid=‘1’ – -’;

注释掉后续 SQL

数据库实际执行：

SELECT * FROM users WHERE uid=‘1’;

返回：admin

由此说明这是一个字符型SQL注入
